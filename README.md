# CMPP-3022-Assignment-2

========================
INFORMATION
========================

Run program:

To run the project from the command line, go to the dist folder and
type the following:

java -jar "StudentRegistration.jar" 

Notes:
-When prompted for text file input, if the example text file is in the same folder as the jar file, type: StudentRegistration.txt

Source files:

Source code is located in "src\studentregistration." in total, there are three java files (ImportStudentList.java, Student.java, StudentRegistration.java) and one example text file (StudentList.txt). This is a netbeans project built with apache ant.
